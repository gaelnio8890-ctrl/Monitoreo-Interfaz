
# MONITOREO INTERFAZ

## Descripción
Dashboard SPA responsivo para el monitoreo y administración
simulada de servidores Cloud.

## Objetivo
Diseñar una interfaz web que permita consultar el estado
de servidores, visualizar métricas y realizar acciones
de administración mediante una navegación sencilla.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Navegación SPA sin recargar la página.
- Diseño responsivo para móvil y escritorio.
- Tarjetas de métricas y alertas.
- Tabla de servidores con búsqueda, filtros y paginación.
- Panel de configuración (Drawer).
- Confirmación de reinicios y despliegues simulados.
- Modo oscuro automático y manual.
- Estados Default, Hover, Focus, Disabled y Loading.

## Estructura del proyecto
- index.html: estructura del Dashboard.
- styles.css: diseño, colores y estilos responsivos.
- script.js: navegación e interacciones.

## Ejecución
Abrir index.html en un navegador web.
